# Support Vector Machine (SVM) — Titanic Dataset

## 📌 Overview
This project explores the Titanic dataset using Python, performs exploratory data analysis (EDA), handles missing values, visualizes patterns, and applies machine learning techniques to understand passenger survival.

## 🎯 Objectives
- Explore and understand the Titanic dataset.
- Perform data cleaning and preprocessing.
- Visualize relationships between passenger features and survival.
- Understand and implement Support Vector Machine (SVM) classification.
- Evaluate model performance using suitable metrics.

## 📊 Dataset
The Titanic dataset is loaded using Seaborn's built-in dataset.

- **Total records:** 891 passengers
- **Original features:** 15 columns
- **Target variable:** `survived`
  - `0` — Did not survive
  - `1` — Survived

## 🛠️ Technologies Used
- Python
- NumPy
- Pandas
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook / Google Colab

## ⚙️ Project Workflow
1. Import required Python libraries.
2. Load and inspect the Titanic dataset.
3. Perform exploratory data analysis.
4. Identify and handle missing values.
5. Remove columns with excessive missing data where appropriate.
6. Prepare features and target variables for classification.
7. Train and evaluate the SVM classifier.
